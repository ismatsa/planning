CHANGELOG — Booking Powertech
=============================

v1.2.0 (2026-11-10)
-------------------
- API SYNC machine-à-machine sous /api/sync/* (clients, véhicules, transfert).
  Accès limité au serveur local (127.0.0.1 / ::1) + clé SYNC_API_KEY.
- Aucune migration SQL. Ajouter SYNC_API_KEY dans app/.env (voir LISEZMOI).

v1.1.0 (2026-11-08)
-------------------
- Immatriculation structurée : choix du pays, saisie marocaine en trois parties
  (numéro, lettre arabe en liste déroulante, région) et caractères contrôlés.
- Affichage des plaques sous forme de badge dans les fiches, recherches et le planning.
- MISE À JOUR OBLIGATOIRE depuis v1.0.0 : après extraction du ZIP, importer une
  seule fois app/migrations/001_immatriculation_pays.sql dans phpMyAdmin.
- Nouvelle installation : importer seulement app/schema.sql (déjà à jour).

v1.0.0 (2026-11-05)
-------------------
- Première version autonome o2switch (PHP 8.3 + MySQL).
- Inclus : comptes utilisateurs (admin/contributeur), planning des rendez-vous
  (semaine, liste, intervenants), métiers et postes (couleurs, ordre),
  créneaux et exceptions, CRM (clients, véhicules, historique propriétaires,
  carnet d'entretien, transfert de propriété), devis (cycle complet, lignes,
  discussion, relances), paramètres.
- Non inclus dans cette version (à venir) : pièces jointes/photos,
  assistant Powertech, intégrations API externes, points à traiter,
  historique des modifications de RDV, organisation personnalisée des lignes.
- Migration SQL : aucune (import initial de app/schema.sql).
